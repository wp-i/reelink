# Reelink

一个仅支持 Windows 的轻量桌面工具：从截图中读出二维码，把混乱的影视名称整理得更清楚。

二维码和重命名共用 520×240 的紧凑默认窗口，可手动调整；切换标签和内容变化不改变窗口大小，长内容在窗口内滚动。资源链接直接放在工具栏，不占用独立页面。

两个工具共用对齐的卡片布局，切换时图标、文字和操作位置保持一致；资源入口使用统一的中性底色。

**本地优先 · 无账号 · 无 LLM · 无遥测**

## 二维码

- 截图后直接 **Ctrl+V**，在本地识别，再点击复制。
- 支持粘贴剪贴板图片、拖入图片、选择 PNG / JPEG / WebP / GIF / BMP 文件。
- 同一张图片中的多个二维码分别展示；结果不会自动打开。
- **Alt+Q** 调用 Windows 截图工具，完成框选后自动解析。Reelink 需要保持运行；快捷键被其他软件占用时可点击窗口底部的快捷键录入新组合，也可截图后粘贴。
- 识别后手动点击复制。截图快捷键在本机保存；没有自动复制、设置或关于面板。

## 重命名

1. 点击「选择文件」或「选择文件夹」，也可直接拖入。应用根据所选项目自动判断，无需切换电影或剧集分类。
2. 查看原名 → 新名，按需编辑，取消勾选不需要修改的项目。
3. 点击应用，之后可撤销最近一批操作；重启后恢复记录仍然保留。

| 类型 | 操作对象 | 示例 |
| --- | --- | --- |
| 电影 | 选中的视频，或文件夹内的视频 | `The.Matrix.1999.1080p.BluRay.mkv` → `The Matrix (1999).mkv` |
| 电视剧 | 剧集文件夹及其中的集数文件 | 文件夹 `Breaking Bad (2008)`；视频 `Breaking Bad - S01E01.mkv` |

**选择文件夹会扫描内部视频，逐项预览。剧集文件夹和内部集数文件一起规范化；不处理独立字幕，不调整目录层级。** 不包含下载、播放、媒体库、刮削海报或后台扫描功能。

本地规则清理常见分辨率、编码、来源和发布标签，尽量保留作品名称与年份。规则无法证明作品身份；没有可靠年份、名称含混等情况需要人工核对。只有用户选中的项目才会执行。重名、非法 Windows 名称、扩展名修改、已变化的源项目会被拒绝。符号链接与重解析点不参与改名。仅大小写变化的重命名暂不支持。

目录扫描限 8 层、5000 个视频。识别 `S01E01`、`1x01`、`第1集` 等集数；`Season 02` 等季目录保持原结构。无法可靠识别的剧集文件保留原名，可在列表编辑。

批次执行前持久化恢复记录；批次中途失败会报告已完成数量，可用撤销恢复已完成的项目。撤销也不会覆盖后来出现的同名项目。恢复记录按批次保留，可以逐批撤销；关闭应用不会清除记录。

## 可选 TMDb

在重命名预览的作品行点击 **放大镜**，输入作品名称，再确认候选作品。剧集匹配会同步更新同组集数文件的名称。**无需注册、无需填写 Key，也无需配置。**

应用读取 TMDb 的公开搜索页，只向 `https://www.themoviedb.org` 发送搜索词、电影/电视剧类型和语言。不会自动查询，不会发送视频内容、图片或完整文件路径。不使用需要凭证的 TMDb API，不内置或分发他人的 Key。

公开网页的结构可能变化，网站拒绝访问或页面无法识别时会给出提示，本地更名仍然可用。不会绕过登录、验证码或访问限制。

影视资料来自 TMDB；Reelink 与 TMDB 无隶属或认证关系。

## 资源网站

工具栏提供两个资源快捷入口。未设置时点击添加，只需粘贴网址，名称自动取域名；设置后点击直接在 Reelink 的独立网页窗口打开，再次点击回到原浏览位置。入口旁的小菜单可修改或删除；更多收藏在紧凑菜单中管理，旧收藏继续保留。初始不内置任何资源站。

链接只保存在本机，添加和修改不会访问网站。打开后由网站按自己的规则提供内容；网页窗口无法调用二维码、剪贴板或本地更名命令。网站兼容性和可用性取决于其自身及 WebView2。

## 开发

新对话开发先读 [AGENTS.md](AGENTS.md)：默认由主代理统筹 GPT-6 系列子任务，分工实现、交叉审查、集中集成与验证。应用运行时不使用大模型。

依赖：Windows 10/11 x64、Node.js 22（22.12 或更新）、Rust stable（至少 1.88）、Visual Studio C++ Build Tools、Microsoft Edge WebView2 Runtime。

```powershell
npm ci
npm run desktop
```

```powershell
npm run build       # TypeScript 检查和界面构建
npm test            # Rust 本地逻辑和真实文件操作测试
npm run package     # Windows 安装程序
```

构建产物：`src-tauri/target/release/reelink.exe`，安装包在 `src-tauri/target/release/bundle/nsis/`。默认安装到当前用户并创建桌面快捷方式，安装包会在缺少 WebView2 时下载其官方引导程序。应用本身不捆绑浏览器或 Node.js。

`npm run dev` 是浏览器中的界面预览，不提供桌面文件操作或本地二维码识别。真实功能请使用 `npm run desktop` 或打包后的应用。

## 结构

```text
src/                       React 界面
src-tauri/src/qr.rs         本地二维码、剪贴板、Windows 框选
src-tauri/src/rename.rs     保守名称解析、预览、执行、持久化撤销
src-tauri/src/tmdb.rs       用户主动触发的 TMDb 搜索
src-tauri/src/resources.rs  用户自定义站点存储和隔离网页窗口
src-tauri/src/lib.rs        命令桥接、单实例、全局快捷键
docs/                      产品边界、隐私、验证说明
.github/workflows/         Windows 检查与手动构建产物
```

界面和剪贴板图片仅存在于内存中。文件改名恢复日志保存在 `%LOCALAPPDATA%\app.reelink.desktop\rename-journals`，包含原始与目标路径。详见 [隐私说明](docs/PRIVACY.md)。
