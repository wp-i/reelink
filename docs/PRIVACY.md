# 隐私与本地数据

Reelink 不收集遥测，不包含广告、账号、更新检查或远程字体。二维码识别和名称规则均在本机执行。

- 剪贴板仅在粘贴、点击读取或框选截图时读取。
- 框选期间暂时隐藏窗口，等待 Windows 截图写入剪贴板；按 Esc 或等待超时会恢复窗口。极短的 Esc 按键可能未被检测，此时会在 45 秒超时后恢复。
- 图片和识别结果仅保存在应用内存。Reelink 不把截图另存到磁盘。
- Windows 截图工具可能根据自身设置自动保存截图；Windows 剪贴板历史或跨设备同步也由系统设置控制。
- 只有点击复制按钮才会把识别内容写入系统剪贴板。
- 截图快捷键保存在 `%LOCALAPPDATA%\app.reelink.desktop\preferences.json`，重启后继续使用；快捷键是否可用会在每次启动时重新检查。
- 只扫描用户选择的目录范围并操作预览中勾选的项目。电影和剧集视频保持扩展名；剧集文件夹及内部集数文件可一起更名。不读取视频内容。
- 本地恢复日志包含文件绝对路径、时间与文件元数据，用于崩溃恢复与撤销，保存在 `%LOCALAPPDATA%\app.reelink.desktop\rename-journals`。卸载后需要自行决定是否保留这些恢复记录；移除记录会失去对应撤销能力。
- 只有主动搜索 TMDb 时，才向 `www.themoviedb.org` 的公开搜索页发送输入的搜索词、类型和语言。TMDb 会按自己的规则处理请求。无需 API Key，不使用用户凭证，也不内置其他人的凭证。
- 搜索只解析网页文本，不执行网页脚本，也不下载网页里的海报、广告或其他外部资源。
- 安装时若缺少 WebView2，安装程序可能联网下载微软运行环境。构建时也需要下载开源依赖；这与应用日常离线运行分开。

二维码内容始终按普通文本显示，不执行命令，也不会自动访问其中的地址。
