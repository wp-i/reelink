# 隐私与本地数据

Reelink 不收集遥测，不包含广告、账号、更新检查或远程字体。二维码识别和名称规则均在本机执行。

- 剪贴板仅在用户粘贴图片或主动读取时读取。屏幕选区使用应用内存中的桌面快照，不读取或轮询系统剪贴板。
- 启动屏幕选区时主窗口会暂时隐藏；框选取消（Esc 或右键）、失焦或超时后退出并恢复窗口。快照及选区只在内存处理，不保存到磁盘。
- 图片和识别结果仅保存在应用内存。Reelink 不把截图另存到磁盘。
- 屏幕选区不调用 Windows 截图工具，因此该流程不会触发其自动保存；用户主动粘贴的图片仍受 Windows 剪贴板历史或跨设备同步设置影响。
- 桌面应用只有在点击复制按钮后才会把识别内容写入系统剪贴板；Chrome 扩展行为见下文。
- 截图快捷键保存在 `%LOCALAPPDATA%\app.reelink.desktop\preferences.json`，重启后继续使用；快捷键是否可用会在每次启动时重新检查。安装版另在当前用户开始菜单提供 `Reelink 截图.lnk`，通过 `--capture` 启动截图；这不需要常驻助手、开机项或联网，也不改变普通桌面快捷方式的打开行为。已运行时请求由单实例转交；前端完成监听握手前会暂存请求并合并重复请求，截图进行中收到的重复请求会丢弃。
- 安装/卸载程序通过无 GUI 参数安装或移除截图快捷方式。程序只更新或删除目标为当前程序且参数精确为 `--capture` 的本地快捷方式，不触碰其他同名快捷方式。卸载会移除该入口，但不会删除用户数据。安装版更改快捷键时同步更新快捷方式和本机设置，更新失败会尝试恢复之前配置；恢复失败会明确显示未同步状态及错误，不会误报为已配置。便携版和开发版没有受管理的链接时只使用应用运行期间注册的快捷键，不自动创建系统链接。
- 更新系统截图入口时，会临时备份此前入口的内容（程序路径、快捷键、图标等），不包含截图或二维码结果。备份为当前用户开始菜单目录中的 `reelink-capture-*.bak`；保存成功后尝试清理，恢复或清理失败时会保留，卸载也不删除这些恢复备份。临时写入文件不向 Windows 注册热键，只有最终的截图入口会执行原生保存。
- `coldStartConfigured` 表示安装版的系统快捷键配置已保存，不代表该组合没有被其他程序占用；`shortcutAvailable` 仅表示应用运行时注册成功。冲突时用户需更改快捷键。系统级快捷键可用性取决于 Windows/Explorer 和其他程序的实际占用情况。
- 只扫描用户选择的目录范围并操作预览中勾选的项目。电影和剧集视频保持扩展名；剧集文件夹及内部集数文件可一起更名。不读取视频内容。
- 本地恢复日志包含文件绝对路径、时间与文件元数据，用于崩溃恢复与撤销，保存在 `%LOCALAPPDATA%\app.reelink.desktop\rename-journals`。卸载后需要自行决定是否保留这些恢复记录；移除记录会失去对应撤销能力。
- 只有主动搜索 TMDb 时，才向 `www.themoviedb.org` 的公开搜索页发送输入的搜索词、类型和语言。TMDb 会按自己的规则处理请求。无需 API Key，不使用用户凭证，也不内置其他人的凭证。
- 搜索只解析网页文本，不执行网页脚本，也不下载网页里的海报、广告或其他外部资源。
- 安装时若缺少 WebView2，安装程序可能联网下载微软运行环境。构建时也需要下载开源依赖；这与应用日常离线运行分开。

Chrome 扩展是独立的可选产品，不依赖桌面应用。用户按快捷键或点击扩展按钮后，扩展只截取当前活动标签页的可见区域；选区覆盖在冻结截图上，裁剪和 jsQR 识别均在扩展本地执行。单个结果自动复制到系统剪贴板；多个结果需点击对应结果旁的「复制」按钮。识别后仍可重新框选或再次复制。关闭选区页、按 Esc、源页面导航或会话到期时才会关闭会话并释放截图，会话最长 120 秒。Chrome 内置页面等无法显示注入式选区时，会使用扩展自己的页面展示截图。

扩展的 `storage.session` 仅保存临时会话元数据和识别出的文本，不保存截图；冻结截图和预览在选区界面及 offscreen 文档的扩展会话内存中，不写入磁盘。扩展不申请网站主机权限，不连接远程服务，不与桌面应用共享命令桥，也不提供文件重命名或收藏站点功能。Chrome 的 `activeTab` 权限只在用户主动调用扩展后临时允许访问当前标签页；使用 `file://` 页面还需由用户在 Chrome 扩展详情页允许文件网址访问。快捷键可在 `chrome://extensions/shortcuts` 管理；它可能与桌面版默认 Alt+Q 冲突。

二维码内容始终按普通文本显示，不执行命令，也不会自动访问其中的地址。

资源网站列表初始为空，由用户自行添加。名称、地址和站点标识保存在 `%LOCALAPPDATA%\app.reelink.desktop\resource-sites.json`；添加、修改和读取列表不会联网。点击网站后，独立 WebView2 窗口会向该网站及网页引用的第三方服务发送正常浏览请求，网站按自身隐私规则处理访问。用户可在可信本地工具栏使用返回、前进、刷新、停止、主页和 HTTP(S) 地址导航；地址栏内容仅在用户按 Enter 后访问。此导航不新增全局浏览历史，站点 WebView2 profile 仍按浏览器正常行为保留 Cookie、登录状态和缓存。网页脚本可以运行，但无权限调用 Reelink 的本地文件、二维码、剪贴板和重命名命令。

各站点的 Cookie、登录状态及浏览缓存保存在 `%LOCALAPPDATA%\app.reelink.desktop\resource-webviews\<站点标识>`，与主窗口及其他收藏的浏览数据目录隔离。删除收藏会关闭对应窗口并移除列表条目，不自动清除该目录；需要清除登录信息时，可先退出应用，再删除对应目录。新窗口链接在原网站窗口打开；文件下载、自定义协议、应用内部地址和本机回环地址会被阻止。网站自身仍可发起后台请求；关闭网站窗口会结束该窗口中的页面。
